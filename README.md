# ИБИ — сайт проекта

Одностраничный сайт интерактивной образовательной платформы для практического освоения «1С:Бухгалтерия 8.3».

## GitHub Pages

Готовая статическая версия находится в папке `docs`: `index.html`, `styles.css`, `script.js` и графические материалы. Она не требует backend, API или платных сервисов.

## Контакты

Перед подачей заявки замените данные-заполнители `Имя основателя`, `@username` и `hello@example.ru` в `docs/index.html` и `app/page.tsx`.
